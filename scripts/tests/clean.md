# 测试 fixture: 0 违规样本

> 用于 scripts/tests/run-tests.sh 回归测试。这个文件应通过 lint,exit code 0。

## 摘要

本 PRD 描述了一个简单的产品列表功能。

## 六、功能需求

| 二级功能 | 三级功能 | 使用角色 | 需求描述 |
| --- | --- | --- | --- |
| 列表 | 查看产品列表 | 租户管理员 | 1. 列表展示当前租户的所有产品,每行展示:产品名、产品 ID、状态、操作。 |
| 列表 | 查看状态分布 | 租户管理员 | 1. 列表顶部展示 4 张概览卡片:产品总数、可开通、席位已满、无许可证。 |
| 搜索筛选 | 搜索产品 | 租户管理员 | 1. 提供搜索框,支持按产品名 / 产品 ID 模糊匹配,结果实时刷新到列表。 |
| 分配 | 分配额度到部门 | 仅租户管理员 | 1. 提供 [+ 分配额度到部门] 按钮,点击后打开分配弹窗。 |
| 分配 | 分配额度到部门 | 仅租户管理员 | 2. 弹窗的填写流程:先选目标部门 → 再选来源许可证 → 最后填多维度数字。 |

## 七、验收标准

- [ ] 列表展示当前租户挂载的所有产品,每行展示"许可证数量"和"剩余 / 总席位"
- [ ] 顶部 4 张概览卡片数字与列表行状态判定一致
