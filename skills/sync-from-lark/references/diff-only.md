# 飞书到本地同步预览

## 适用场景

- PM 说“先看看同步回来会改什么”“只比较，不要写”。
- 在机械回拉前确认目标文档和差异范围。

## 流程

1. 读取本地 Markdown，剥离 frontmatter 后取得正文。
2. 拉取绑定的飞书 Docx Markdown；信息明显丢失时再读取 full / with-ids 辅助判断。
3. 按章节对齐：飞书新增、飞书删除、双方文字不同、只有格式不同。
4. 只报告差异，不判断它们是否应改变产品决定、规格、原型或实现。
5. 若差异明显涉及上述产品资产，建议转 `/pmai-lark-review`；不得在本 skill 内继续解释和落地。

## 输出

```markdown
## 飞书同步预览

| 章节 | 差异类型 | 本地 | 飞书 |
|---|---|---|---|
| ... | ... | ... | ... |

结论：可以按飞书机械同步回本地 / 这些变化需要先进入飞书评审判断。
```

## 规则

- 不写飞书。
- 不改本地。
- 不把格式差异夸大成产品差异。
- 不代替 `/pmai-lark-review` 判断影响。
