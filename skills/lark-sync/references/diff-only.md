# 只 diff，不修改

## 适用场景

- 用户说"看哪里不一致"、"比一下"、"先别改"
- 当前不知道本地和飞书谁是最终版
- 需要 PM 先判断同步方向

## 流程

1. 读取本地 markdown，剥离 frontmatter 后取正文。
2. 拉取飞书内容。优先取 markdown；如果 markdown 信息丢失明显，再取 HTML / with ids 辅助判断。
3. 按章节对齐差异：
   - 本地有、飞书没有
   - 飞书有、本地没有
   - 两边都有但口径不同
   - 只是格式差异，不是产品差异
4. 输出建议动作：
   - 建议本地精细同步到飞书
   - 建议飞书回拉覆盖本地
   - 建议整篇覆盖发布
   - 需要 PM 决策

## 输出格式

```markdown
## 飞书 / 本地差异

| 章节 | 差异类型 | 本地 | 飞书 | 建议 |
|---|---|---|---|---|
| ... | ... | ... | ... | ... |

结论：建议走模式 A/B/C，或先由 PM 决策。
```

## 规则

- 不写飞书。
- 不改本地。
- 不把格式差异夸大成产品差异。
- 对产品口径差异要锚定具体短句，不只说"不一致"。
