# §七 章节顺序约束（按文档类型）

> 本文件是 [`PM-VIEW-RULES.md`](../PM-VIEW-RULES.md) §七 的物理拆分。配套阅读：主文件 §五（功能清单格式）/ §六（关键产品决策格式）。

## `docs/modules/<模块>/discussion.md`

建议顺序：

1. 背景与目标
2. 当前产品现状
3. 待确认问题
4. 讨论记录
5. 参考材料

## `docs/modules/<模块>/decisions.md`

建议顺序：

1. 已拍板决策
2. 共同理由
3. 否过的方案
4. 待复核决策
5. 变更记录

## `docs/modules/<模块>/spec.md`

建议顺序：

1. 模块定位
2. 功能清单
3. 信息模型
4. 业务规则
5. 页面 / 交互口径
6. 验收路径
7. 边界与非目标
8. 参考材料

## `brief.md` / `analysis.md` / `prd.md`

这些是历史或按需产物。各 skill 内定义章节，本文件不重复约束。
