# 共享参考：项目决策记录（冻结档）

## 这是什么

项目奠基轮（`/pmai-strategy` 方向讨论、`/pmai-init-project` step C 奠基、或某个需求收尾时产出的**项目级理路**）会产生一层"为什么这么拼"的内容——护城河论证、机制整体设计意图、交互咬合推导、演进故事。脊柱五件套按"离散事实"切，**装不下跨文件理路**；防腐铁律又（正确地）禁止"活的并行综合稿"。所以这层理路逃成野文档。

**冻结档接住它**：`docs/decisions/<日期>-<slug>.md`，写一次、带日期、不维护。它**从不假装是现状**（当前真相永远看脊柱），所以结构上无法和脊柱竞争"当前真相"的名分 → 防腐铁律杀不到它。和模块 `decisions.md` 同构，只是尺度从单模块抬到项目奠基。

## 什么时候冻（门槛判断）

**只在本轮讨论真产出了"项目级理路"时冻**，且只在**已有讨论产出**处顺手冻——不新增"从对话即时自动提取"机制（那本质是 AI 判断、做不到 100% 自动，属另一话题）。

| 情形 | 冻不冻 |
|---|---|
| 本轮定/改了护城河论证、几个机制怎么整体咬合、关键交互理念的推导、v2 演进方向 | **冻一份** |
| 纯微调（改一句定位措辞 / 加一条术语 / 调一个字段名） | **不冻**（无实质理路；记录过多反成噪声，§5 R3） |
| 离散事实（某条规则 / 模块功能清单 / 单个字段语义） | **不冻**——它们各有脊柱家（PRODUCT-RULES / modules）；冻结档只装跨文件理路 |
| 单模块范围内的决策（为什么这版选 A 不选 B） | **不冻**——由模块 `decisions.md` + req-events 承接，本机制不碰模块内决策 |

AI 拿不准"算不算实质理路"时，用一句话向 PM 确认再决定，不擅自冻 / 不擅自跳。

## 怎么冻（人在环：AI 提议 + PM 确认）

1. AI 判断本轮有实质理路 → **提议**冻一份，给 PM 一句话：「这轮定了 <一句话理路主题>，我冻一份项目决策记录留作历史坐标，好吗？」
2. PM 点头 → AI 按 `$PMAI_HOME/templates/decision-record.md.tmpl` 写 `docs/decisions/<日期>-<slug>.md`：
   - **理路节**：把本轮讨论里"为什么这么拼"的推导写进去（护城河 / 机制整体 / 交互咬合 / 演进，按实际有的写）。
   - **事实节**：冻结当时的关键事实摘要（带日期、自包含）+ 指针指当前真相源（F-D1：只给指针会让读者拿 then-why 配 now-what，所以并存）。
   - **两节都不可省**：只填理路节、事实节只丢个指针 = 退回 F-D1 反模式（读者拿"那时为什么"配"现在是什么"对不上）。事实摘要必须带日期、自包含读得懂。
3. 落盘后**顺手把它挂进 `docs/PRODUCT-STATE.md` 索引**（脊柱索引展开层一条指向 `docs/decisions/`），后续 AI 才读得到。
4. 呈交 PM 审 diff（路径 + 一句摘要即可，不复读全文）。

## 边界（防 review 加回）

- **不做活的第五份脊柱**——理路走冻结档，不走持续维护的活文档（触防腐铁律）。
- **写一次不维护**——方向变（pivot）写**新的一份**，旧的留作历史坐标，不回改旧档。
- **PM 话术不出内部词**——给 PM 的话只说「冻一份项目决策记录留底」，不出现"出口②/冻结档/索引展开层"等内部词（F-G4）。
