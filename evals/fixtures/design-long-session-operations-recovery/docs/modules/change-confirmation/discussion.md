# 租户开通与接管：设计讨论

## 本轮目标

覆盖租户首次开通、管理员持续新增成员、SSO 首次登录成员和后续属性变化。

## 已知上下文

- 管理员会持续新增成员，不是只做首次建租户。
- SSO 会持续带来首次登录成员，属性映射可能变化。
- 已有许可证状态页和身份源属性映射页。
- “独立开通页”与“现有成员页内承接”构成真实信息结构分叉。

## 本轮决定

- 成员进入范围后按当前规则计算可用产品。
- SSO 属性变化触发重新计算，不要求管理员逐人重复开通。

## 未决问题

- 初始密码是否只展示一次？
- 成员离开范围后，席位是否自动释放？

两项都没有 PM 决定，不能写入规格。
