# 发布前变更确认：模块规格

## 模块定位

为产品经理提供单条发布前变更的查看、确认和留痕。

## 信息模型

| 对象 | 必要信息 | 状态 |
|---|---|---|
| 发布前变更 | 标题、摘要、当前状态、确认时间 | 待处理 / 已确认 |
| 确认记录 | 动作、时间 | 由变更记录持有 |

## 核心动作

### 查看变更

- 触发：产品经理打开一条发布前变更。
- 展示：标题、摘要、当前状态；已有确认时展示确认时间。
- 异常：变更不存在时显示明确的无数据结果，不创建新记录。

### 确认变更

- 前置：变更当前为待处理。
- 动作：产品经理选择确认。
- 结果：状态变为已确认，记录确认时间。
- 重复操作：已确认状态不重复写入新的确认记录。

### 保留待处理

- 前置：变更当前为待处理。
- 动作：产品经理离开或明确保留待处理。
- 结果：状态保持待处理，不生成确认时间。

## 权限与边界

MVP 只验证单一产品经理使用，不建立多人权限和审批关系。系统不替用户判断是否应该发布，也不执行外部发布。

## 验收标准

1. 打开一条变更能看到标题、摘要和待处理状态。
2. 完成确认后状态变为已确认并显示确认时间。
3. 刷新或重新打开后状态和确认时间保持一致。
4. 保留待处理不会伪造确认时间。
5. 不存在的变更给出可理解的无数据结果。
