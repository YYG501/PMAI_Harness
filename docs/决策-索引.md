# 决策索引

> 本文件是 PMAI framework 所有**单点决策记录**的总索引。
>
> **用途**：记录"为什么砍了 X / 为什么选 A 不选 B"这类单点决策；future-self 接续时不用 grep 半天。
>
> **不是什么**：
> - 不是大改 / 多 vp 方案 → 用 [`设计/_模板-方案.md`](./设计/_模板-方案.md) 起手，完整 §0-§7 结构
> - 不是运行时状态 → [`RUNTIME.md`](../RUNTIME.md)（项目章程 / 当前位置 / 测试基线）
> - 不是 TODO 清单 → [`TODOS.md`](../TODOS.md)
>
> **服务对象**：主仓 framework 开发者（PM + AI）；**不进消费仓同步 SOP**

---

## 决策文档生命周期

| 阶段 | 位置 | 命名 |
|---|---|---|
| 起草中 | `docs/设计/` | `决策-D<N>-<主题>.md` |
| PM 锁定，待执行 | `docs/执行中/` | 同上 |
| 落地，归档 | `docs/归档/完成/D<编号>-<主题>/` | `决策.md`（随主方案进同一子目录）|
| 被否决/废弃 | `docs/归档/废弃/` | 保留原名 |

新决策起手：`cp docs/设计/_模板-决策.md docs/设计/决策-D<N>-<主题>.md`

## 决策记录的 4 个容器（边界）

| 容器 | 何时用 |
|---|---|
| `docs/设计/决策-D<N>-<主题>.md` → 落地后到 `docs/归档/完成/D<编号>-<主题>/决策.md` | 单点决策 / 砍了 X / 选 A 不选 B / 1 页 4 段 |
| `docs/设计/<主题>.md` → `docs/执行中/<主题>.md` → `docs/归档/完成/D<编号>-<主题>/主方案.md` | 大改 / 多 vp / 需要 §0 痛点锁防 review 膨胀 |
| `RUNTIME.md` | 项目章程 + 当前位置 + 测试基线 + 最近活动 |
| `TODOS.md` | 延迟项 / TD-X 清单 / 触发条件 |

新决策按规模选容器；不要重复写 4 处。
